# Contenu requis avant mise en ligne

Le code est prêt à recevoir les données réelles suivantes. Elles ne sont pas inventées dans le site :

- téléphone et numéro WhatsApp (`NEXT_PUBLIC_PHONE`, `NEXT_PUBLIC_WHATSAPP`) ;
- e-mail, adresse, ville, code postal et horaires ;
- zones d'intervention réellement couvertes ;
- raison sociale et mentions légales ;
- liens sociaux et fiche Google Business Profile ;
- réalisations réelles avec autorisation de publication ;
- qualifications, garanties, partenaires et chiffres-clés documentés ;
- photos client finales si les illustrations éditoriales générées doivent être remplacées.

Sans numéro WhatsApp, le formulaire affiche volontairement une erreur de configuration et ne prétend pas envoyer les données.
