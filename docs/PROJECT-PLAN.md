# Project plan

## Phase realisee

- Base Next.js App Router, TypeScript, Tailwind CSS.
- Contenu centralise dans `src/content/pages.ts`.
- Configuration centrale dans `src/config/site.ts`.
- Layout, header, navigation mobile, footer, hero, trust bar, cartes, processus, FAQ, CTA, contact.
- Pages SEO principales generees statiquement.
- Sitemap, robots, canonicals, Open Graph et JSON-LD.
- Tests de base, lint, typecheck et build production.

## Suite recommandee

1. Remplacer les illustrations éditoriales par des photos client lorsque disponibles.
2. Completer les coordonnees et mentions legales.
3. Ajouter les vraies realisations.
4. Enrichir les pages avec textes experts plus longs.
5. Lancer audits Playwright, Axe et Lighthouse avec navigateur.
