# Brief de génération des images

Dix illustrations éditoriales ont été générées avec l'outil intégré OpenAI, dans une direction photo réaliste: architecture marocaine contemporaine, eau naturelle, installations plausibles, sans marque, logo, texte ni watermark. Les prompts finaux demandaient respectivement une piscine de villa, un technicien d'entretien, un local technique, une fontaine architecturale, un spa extérieur, un sauna/hammam, un chantier, une rénovation, des équipements et un traitement UV.

Format source : 1536 x 1024. Format livré : WebP, largeur maximale 1920 px, qualité 82. Les héros utilisent `next/image` avec préchargement et priorité réseau. Ces images sont des illustrations, pas des réalisations Expert Pool Maroc.
